# Resume Builder

https://resume-builder-two-nu-40.vercel.app/

A React CV application built as part of The Odin Project curriculum. Users can enter, submit, edit, and display personal, educational, and practical experience information.

## Features

- General information section
- Education section
- Practical experience section
- Edit and submit functionality
- React state and props
- Responsive design
- Multiline job responsibilities

## Built With

- React
- Vite
- JavaScript
- CSS

## Run Locally

```bash
npm install
npm run dev
